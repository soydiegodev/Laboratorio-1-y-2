# HolaYo - Laboratorios 1 y 2
**Materia:** Aplicaciones Móviles    
**Alumno:** Diego Montaño 

Proyecto Android nativo desarrollado en Kotlin para la materia **Aplicaciones Móviles**.

## Registros de Práctica

Para conocer el detalle de las pruebas, observaciones experimentales y checklists de salida, consultar los siguientes documentos de registro:

- **[Registro Laboratorio 1](Registro_LABORATORIO_1.md):** 
  - Instalación y puesta a punto de Android Studio y emulador (`Pixel_9_Pro`).
  - Creación del proyecto inicial `HolaYo` (`Empty Views Activity`, `minSdk 26`).
  - Despliegue en dispositivo físico y generación/medición del APK debug.

- **[Registro Laboratorio 2](Registro_LABORATORIO_2.md):**
  - Navegación e Intents explícitos entre pantallas con envío de datos.
  - *Tabla del Experimentador*: Pruebas sistemáticas de transición de estados del ciclo de vida (Home, recientes, bloqueo de pantalla, notificaciones).
  - *Comportamiento ante rotación*: Pérdida de variables de instancia. 
  - *Muerte por memoria*: Simulación de liquidación de proceso con `adb shell am kill` y análisis de continuidad de estado.
